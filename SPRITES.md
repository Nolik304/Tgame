# СПРАЙТЫ «Лестницы Бога» — реестр замены

Каждый спрайт в игре — **слот**. Игра пытается загрузить твой PNG по указанному пути.
Если файла нет — рисуется встроенный procedural-аналог (игра никогда не ломается).

## Требования к файлам

- Формат: **PNG с прозрачным фоном** (иначе будет непрозрачный квадрат!)
- Размер: любой, игра подгонит сама. Рекомендуемые значения — в таблице.
- Стиль: плоский с мягким светом, тёмная обводка ~3px — под общий арт игры.
- После замены — просто перезапусти `npm run dev` / пересобери проект.
